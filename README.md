# 📊 Números Acima da Média

Este projeto foi desenvolvido em **Java** para calcular a média de três números e verificar quantos deles estão **acima da média calculada**.

## 💻 Tecnologias

* Java
* `Scanner`
* Estrutura condicional `if`
* `printf`
* Variáveis do tipo `double` e `int`

## 📋 Funcionamento

O programa:

1. Recebe três números (`n1`, `n2` e `n3`).
2. Calcula a média dos três valores.
3. Compara cada número com a média.
4. Conta quantos números são maiores que a média.
5. Exibe a quantidade encontrada.

A média é calculada através da fórmula:

```text
Média = (n1 + n2 + n3) / 3
```

## ▶️ Exemplo de entrada

```text
10 20 30
```

## 🧮 Cálculo

A média será:

```text
(10 + 20 + 30) / 3 = 20
```

Comparando os valores:

* `10` → abaixo da média ❌
* `20` → igual à média ❌
* `30` → acima da média ✅

## 📤 Exemplo de saída

```text
1
```
